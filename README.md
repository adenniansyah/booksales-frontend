📚 BookSales - Fitur Registrasi User

Ini adalah tampilan depan (Frontend) dari aplikasi BookSales yang fokus pada fitur pendaftaran akun baru. Dibuat pakai React JS dan nyambung langsung ke server Laravel.

Fitur Andalan:
✅ Form Lengkap: Input Nama, Email, Username, & Password.
✅ Anti Error: Ada validasi otomatis (cek email bener gak, password kurang panjang gak).
✅ Cepat & Smooth: Pindah halaman tanpa reload browser berkat React Router.
✅ Tampilan Kece: Desain bersih, modern, dan nyaman dibuka di HP maupun Laptop.
